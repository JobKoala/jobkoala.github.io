Close-up · Basic Information Module

Name · user_name

The text field accepts a free-text name. If Required is enabled, users must answer it.

Residence · residence

Set Chinese and English labels and values for each option. For example, Within Australia maps to AU.

Module and Field Ordering Are Separate

Order the five modules first, then move fields within each module. Reordering Name and Residence only affects Basic Information.

Impact on the AppOnly the active template affects the app. Turning off Show Assessment Questionnaire skips the introduction and form, taking users directly to adviser consultation.
