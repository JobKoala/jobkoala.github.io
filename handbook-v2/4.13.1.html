4.13.1Adviser Management

One adviser can be linked to several visa categories using a shared profile. Category names and order appear on the app service page.

Once visa categories are configured, do not arbitrarily rename, reorder, disable or delete them.

Adviser Profiles and Service Categories

Check the Adviser's Services First

For example, Meg88888 is linked to work visas and skilled migration. Check all linked categories when updating the profile or cover.

Prepare Media by Content Type

Video profiles require a cover and video; image-and-text profiles require a cover and images. Sort order and enabled status belong to the adviser record.

How Categories Affect the App

Check Listed Adviser Counts First

The example shows two listed advisers for Tourist Visa. Lower sort values appear first; bilingual descriptions are for admin use only.

Existing Entitlements Remain Valid

Disabled categories no longer appear in the app. Disabling or deleting a category retains adviser profiles and previously purchased entitlements.

If Changes Are NeededConfirm the affected categories and advisers, then check category names and ordering on the app service page.
