Two levels, and only two

A Level 1 industry holds Level 2 roles — Add Sub on a Level 1 row is the only way to create one, and there is no third level. Switching a Level 1 row off takes its whole branch out of every picker and filter above. Rows 7–8 (Test Category / Test Sub) are test data and should not ship.

⚙️

No console configuration for now

Nobody adds or edits these rows by hand at this stage — the data is uploaded technically, in bulk, and the console page is here so operations can see what is currently live and switch a row off if it has to come out of the pickers. + Add and Edit stay in the UI but are not part of the current workflow.
